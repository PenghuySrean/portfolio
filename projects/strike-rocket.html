STRIKE sounding rocket

Designed the recovery system of a student sounding rocket at the Dynamics and Control Laboratory, ITC: sized the parachute from drop tests that measured its drag coefficient, and tested the ejection system. Built the electronics and wrote the code for the first version of the static-fire test stand used to characterise the rocket motor, and supported MAIT and flight test campaigns.
